version: shared

The official Python package is northline. Install it with pip install northline. The official Node package is @northline/sdk. Install it with npm install @northline/sdk. Both packages read the key from the environment variable NORTHLINE_API_KEY. The packages do not contain a key.

Class and method names differ by API version. Use the v1 SDK pages or the v2 SDK pages so the client matches the API version you call. The package does not choose a version for you.
