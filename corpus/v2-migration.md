title: Moving from v1 to v2
version: v2
---

Use this page when moving from v1 to v2. Replace external_id with account_ref. Replace the v1 invoice finalize call with the v2 issue call documented on the v2 invoices page. Replace the usage field with meter_id, and send quantity as a decimal string. Replace the v1 webhook signature header with Northline-Signature-256.

Read each v2 resource page for the current request bodies.
